# Set up this computer

Orqiva's setup program installs what this computer needs. This step checks that it is all there.

| Needed          | Why                                                                        |
| --------------- | -------------------------------------------------------------------------- |
| **Node.js 22**  | the `orq` command and Claude Code run on it                                |
| **git**         | a task is finished by a commit, and the commit message carries the task id |
| **Claude Code** | the thing that writes the code, inside the loop                            |

**Check environment** reports each one and what to install if it is missing.

This step completes once this computer is signed in to an Orqiva server.
